# Nom de fiche App Store

Source de vérité du **nom affiché sur la fiche** ASC (pas le nom sous l’icône iPhone, qui reste `BLOMIX`).

- Limite Apple : **30** caractères / langue (espaces compris).
- Poussé avec `fastlane metadata` / `release` sur la version **7.5**.
- Fastlane génère `name.txt` dans les métadonnées deliver.
