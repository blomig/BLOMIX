# Sous-titre App Store

Source de vérité du champ **Sous-titre** ASC.

- Limite Apple : **30** caractères / langue.
- Poussé avec `fastlane metadata` / `release` sur la version **7.5**.
- Fastlane génère `subtitle.txt` dans les métadonnées deliver.
- Ne pas répéter un mot déjà dans le nom de fiche.
